# 构图与图例学习库

从表达目的、空间骨架和同题对照学习图解表达。

来源目录 313 项；随站可看原图 57 项，其余仅列来源与分析。

网站文件在 public/，源码在 src/。完整原图片、PDF、PPT 和模型文件保存在 herry521/diagram-gallery-assets 私有仓库；受限文件不会向公众再分发。

代码采用 MIT。第三方媒体分别沿用原许可，见 THIRD_PARTY_NOTICES.json 和网页素材署名页；本库用于非商业学习，不将素材统一改为 MIT。

## 浏览方式

[在线图库](https://herry521.github.io/diagram-gallery/) 使用 480/960 像素两档本地 WebP 缩略图，点开详情才读取完整预览。首批呈现 12 张卡片，接近底部再追加 12 张；可视区附近的缩略图最多三路并发加载。原图、水印和来源入口均保留。

全部分类与关键词检索在轻索引中完成。单项详情在线按需读取同站 JSON；直接以 file:// 打开时，通过同目录备用脚本读取详情，不依赖跨域 fetch。完整个人素材及受限媒体仍在私有素材仓库。

GitHub Pages 提供静态托管；这些按需加载和瀑布式浏览由浏览器 JavaScript 执行，无需服务端应用。
