# 构图与图例学习库

从表达目的、空间骨架和同题对照学习图解表达。

来源目录 313 项，全部提供真实图例预览与本地缩略图；在线与本地采用相同学习路径，不以示意骨架替代原图。

网站文件在 public/，源码在 src/。此库供个人非商业学习，当前 GitHub Pages 站点可被公众访问。个人学习用途不改变第三方许可。完整 PDF、PPT 和模型文件保存在 herry521/diagram-gallery-assets 私有仓库；仅原文件许可允许的部分另随站提供下载。

代码采用 MIT。第三方媒体分别沿用原许可，见 THIRD_PARTY_NOTICES.json 和网页素材署名页；不将素材统一改为 MIT。

## 浏览与加载

[在线图库](https://herry521.github.io/diagram-gallery/) 使用 480/960 像素两档本地 WebP 缩略图，点详情才读取完整预览。首批 12 张、滚动追加 12 张；可视区附近缩略图最多三路并发加载，保留手动“加载更多”。

全部分类与关键词检索基于轻索引。单项详情在线按需读取同站 JSON；直接以 file:// 打开时，使用同目录备用脚本读取详情。全部图例预览均在站点内，不依赖外部图片服务；受限 PDF、PPT 等原件仍在私有素材仓库。

GitHub Pages 提供静态托管；按需加载与瀑布式浏览由浏览器 JavaScript 执行，无需服务端应用。

格式筛选与文件数量依据完整收藏（包含私有备份），与本地一致；随站文件范围单独记为 `site_*`。PPT、Visio 等原件未随站提供时，卡片直接链接到对应私有备份，不再标为“静态参考”。
